# Task: Create a Premium Cinematic Motion Graphics Explainer — How AI Agents Work

You are an expert motion graphics designer, creative director, technical animator, and video production specialist.

Using the **Lemo Opuscar plugin**, create a visually stunning, professional, cinematic explainer video demonstrating **how AI agents work**.

The animation should resemble the production quality and visual sophistication of premium technology product launches from Apple, Google, Linear, and Stripe.

Use these brands only as references for production quality, motion design principles, and visual sophistication. Create an entirely original visual identity without copying their assets, layouts, or branding.

## 1. Primary Objective

Create a **40–45-second, 16:9, 1920×1080, 30 FPS** animated explainer.

The video must visually communicate how an AI agent receives a user request, reasons about the task, plans its actions, selects tools, executes a workflow, and returns a completed result.

The central idea:

**An AI agent doesn't just generate an answer. It can use tools and execute actions to complete a task.**

The viewer should understand this concept even when watching without sound.

However, this is not merely an educational animation. It must also serve as a high-quality demonstration of what Lemo Opuscar and Claude Code can produce.

Prioritize:

1. Exceptional visual quality.
2. Cinematic motion design.
3. Clear visual storytelling.
4. Seamless transitions between scenes.
5. Sophisticated animated interfaces.
6. Accurate technical representation.
7. Smooth, professional animation timing.

**Do not create a generic slideshow, PowerPoint-style presentation, or sequence of disconnected diagrams.**

The entire animation should feel like one continuous cinematic experience.

## 2. Creative Direction

### Visual Identity

Use a premium, modern technology aesthetic.

**Background:**
- Deep charcoal or near-black.
- Subtle atmospheric gradients.
- Soft ambient lighting.
- Restrained use of glow effects.

**Typography:**
- Modern sans-serif typography.
- Strong visual hierarchy.
- Large, bold headings.
- Minimal supporting text.
- Precise alignment and generous spacing.

**Accent Colors:**
- Electric blue for agent intelligence and reasoning.
- Violet for planning and orchestration.
- Cyan for tool execution and data movement.
- Emerald green for successful completion.

Use color intentionally to communicate meaning rather than decorating every element.

### Interface Design

Create polished, realistic-looking fictional software interfaces.

Possible elements:

- AI assistant conversation interface.
- Floating task cards.
- Animated planning steps.
- Tool-selection panels.
- Browser windows.
- API request indicators.
- Database query visualizations.
- Progress indicators.
- Final results dashboard.

All interfaces must be original.

Avoid generic AI brain imagery, humanoid robots, excessive particle effects, and meaningless glowing network diagrams.

### Motion Design

Use:

- Smooth camera movements.
- Shared-element transitions.
- Spatial transformations.
- Layered depth and parallax.
- Precise easing.
- Animated data flow.
- UI micro-interactions.
- Subtle motion blur where supported.
- Meaningful object continuity.

Animations should feel physically and visually connected.

For example, a user request card should transform into an agent task card, which expands into a planning interface, which then connects to tool-execution panels.

Do not simply fade out one scene and fade in another.

# 4. Critical Animation Requirements

The animation must feel like one cohesive film.

### Shared-Element Transitions

Preserve visual continuity between scenes.

Examples:

- User message → Agent task card.
- Agent task card → Planning interface.
- Planning cards → Tool-selection panels.
- Tool panels → Browser and execution interfaces.
- Extracted information → Results dashboard.
- Results dashboard → Complete workflow overview.

Avoid hard cuts unless they are intentionally motivated.

### Camera Movement

Use restrained cinematic camera motion.

Examples:

- Slow push-ins.
- Lateral tracking.
- Controlled pullbacks.
- Spatial transitions between interface layers.

Camera movement should guide attention rather than create unnecessary spectacle.

### Timing

Use smooth easing and carefully coordinated animation timing.

Avoid:

- Abrupt linear movement.
- Excessively fast transitions.
- Long periods of static content.
- Multiple competing focal points.
- Text appearing too briefly to read.

Every animation should communicate something meaningful.
